# Dos Studio

**Dos Studio** is a comprehensive management system designed for self-photography studios. It streamlines operations by integrating booking management, inventory control, employee monitoring, and data analysis into a unified platform.

## Features

### 📅 Booking Management
- **Reservation Handling**: Manage customer bookings efficiently.
- **Payment Verification**: Confirm payments through integrated systems.
- **Daily Summaries**: Generate reports for daily bookings and activities.

### 📦 Inventory Control
- **Real-Time Tracking**: Monitor stock levels and resources.
- **Error Alerts**: Receive notifications for printing errors and low stock.
- **Data Integration**: Sync data with external tools like Excel for historical tracking.

### 👥 Employee Monitoring
- **Attendance Tracking**: Monitor employee attendance and schedules.
- **Performance Metrics**: Assess employee performance and productivity.
- **Role Management**: Assign and manage roles within the studio.

### 📊 Analysis & Forecasting
- **Data Analytics**: Analyze historical data for insights.
- **Revenue Forecasting**: Predict future revenue based on trends.
- **Inventory Forecasting**: Estimate future inventory needs to prevent shortages.

## Tech Stack

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: PHP
- **Database**: MySQL
- **Tools**: Excel for data tracking, Messenger for payment verification
